What is LocaLens?

Overview

A static, zero-backend web app for exploring any point on Earth. Search, click, or use GPS — get instant location intelligence with no sign-up, no API key, no server.

Input methods
  • Type any address or place name
  • Enter lat/lon coordinates directly
  • Click anywhere on the map
  • One-click GPS "Locate Me"
Output
  • Human-readable address
  • Elevation above sea level
  • Live weather + UV + sun times
  • Coordinates in DD — Decimal Degrees (e.g. 51.5074°) and DMS — Degrees°Minutes'Seconds" (e.g. 51°30'26"N)

Feature Set

All free, all instant

Location
  • Address ↔ coordinates geocoding
  • Decimal degrees & DMS formats
  • 8-character Geohash
  • Copy to clipboard
Map
  • 6 styles — Street, Dark, Light, Satellite, Terrain, Topo
  • Dark / light UI mode
  • Mobile fullscreen map
Elevation
  • Metres above sea level
  • Via Open-Meteo (no key)
Weather & Sun
  • Condition, temperature, humidity
  • Wind speed, precipitation, cloud cover
  • UV index
  • Sunrise, sunset, timezone, UTC offset

Lookup Pipeline

Every input path converges on lookupCoords()

Inputaddress / coords / click / GPS
→
lookupCoords()lat, lon
→
Geocode + Elevationparallel fetch
→
loadMoreInfo()weather, UV, sun
Design note
Reverse geocode and elevation fire in parallel. Weather/UV/sun load in the background and fail silently — they never block the primary result.
Map interaction
MapUpdater responds only to navTarget.id changes — not center/zoom — so user pan/zoom is never overridden. MapClickHandler keeps zoomRef in sync so map clicks preserve the current zoom level.

Tech Stack

Fully static · no backend · no API keys

UI & Build
  • React 18 + Vite
  • React-Leaflet — interactive map
  • Single component architecture — all logic in App.jsx
  • CSS custom properties for theming (data-theme)
Geocoding
  • Nominatim / OSM — forward + reverse
  • Max 1 req/sec, no key required
Data APIs
  • Open-Meteo — elevation, weather, UV, sun
  • Free for non-commercial use, no rate limit
Map Tiles
  • OpenStreetMap — street
  • CartoDB — dark & light
  • Esri World Imagery — satellite
  • Stadia/Stamen — terrain
  • OpenTopoMap — topo

Deployment

Static site — deploy anywhere

Cloudflare Pages primary
  • npm run build → dist/
  • Auto-deploys on every push
  • Live at localens.pages.dev
GitHub Pages
  • npm run build:gh sets /LocaLens/ base path
  • npm run deploy publishes via gh-pages
Dev commands
  • npm run dev — localhost:5173
  • npm run build — production dist
  • npm run lint — ESLint (zero warnings)
Zero infrastructure
No server, no database, no auth. Drop the dist/ folder on any static host and it just works.
